# 🏙️ Smart City Complaint Management System

A web-based complaint management system developed using **Python and Django**.

The system allows citizens to report civic problems such as street light issues, garbage, water supply problems, potholes, etc. Citizens can track their complaints while administrators can manage complaints and update their status.

---

## 📌 Project Overview

The **Smart City Complaint Management System** provides a simple digital platform for managing civic complaints.

Instead of handling complaints manually, the system allows:

- Citizens to register and login
- Citizens to submit complaints
- Upload complaint images
- Track submitted complaints
- View complete complaint details
- Administrators to manage complaints
- Administrators to update complaint status
- Dashboard statistics and charts
